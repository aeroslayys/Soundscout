A SIMPLE SCALE

One score. A clearer picture.

Community quietness ratings use a five-point scale to describe the general sound experience.

1LoudHigh noise, hard to tune out
2LivelyEnergetic, lots happening
3ModerateA balanced, everyday atmosphere
4CalmComfortable for conversation
5SilentVery little ambient noise

Scores are community observations, not a promise of conditions at the time you visit. Venue noise can change with the hour, day and crowd.

BEHIND THE BUILD

Built from a simple
what if?

What if choosing a café wasn't just about its photos and star rating? SoundScout grew from that question into a full-stack, community-powered discovery project.

THE BUILD LOG

One idea, a lot of moving parts.

SoundScout is developed as a connected web and mobile experience, with a backend that brings venue discovery, community contributions and sound insights together.

01

Start with the missing context

The first step was to rethink what a venue listing should tell you. Alongside the usual details, SoundScout centres quietness, sound reports and accessibility information.

02

Build the discovery experience

An interactive map, venue search, quietness ratings, Quiet Near Me and a sound heatmap make community information easier to explore geographically.

03

Bring sound into the picture

Optional short ambient recordings can be analysed to derive digital recording-level information. Reports and time-based views add context to those observations.

04

Make it a community product

Accounts, profiles, venue submissions, content flags, approvals and moderation workflows help people contribute while giving the project ways to maintain data quality.

05

Take it beyond the browser

The project includes a browser-based application and an Android mobile app built with React Native and Expo, supported by a shared backend.

06

Run it, learn, improve

Self-hosted services, containerised deployment and ongoing iteration keep the project moving. SoundScout is still actively evolving, and community feedback helps shape what comes next.

THE TOOLBOX

A connected stack.

The project combines web technologies, backend services, audio analysis and mobile development.

01 / EXPERIENCEWeb application

Browser-based venue discovery, profiles and interactive map experiences.

02 / MOBILEReact Native + Expo

A companion Android application for discovery on the go.

03 / PLATFORMBackend + database

APIs, persistent venue and user data, and community workflows.

04 / AUDIOSignal analysis

Optional ambient audio processing and derived sound-level insights.

05 / OPERATIONSContainers + self-hosting

Containerised services and deployment across the project's environment.

06 / COMMUNITYModeration tools

Venue review, user reports and administrative controls.

HOW TO BECOME A PARTNER

Four steps to get started.

We verify each venue and partner request before granting dashboard access.

01

Find or submit your venue

Check whether your venue is already listed on SoundScout. If it isn't, submit it for review through the app.

02

Request an invitation

Send us the venue name, its public location and your role. An owner, manager or authorised representative should make the request.

03

Complete verification

Our team reviews the venue and your connection to it. Approved partners receive an invitation by email.

04

Accept and start sharing

Open the invitation, create or sign in to your SoundScout account, and use the partner dashboard to publish announcements and view recent ratings.
